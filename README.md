## 🚀 Sobre Mim

Sou **Desenvolvedor Full Stack** com foco em **Java, Spring Boot, React e TypeScript**, desenvolvendo aplicações web, APIs REST e aplicações mobile.

Tenho experiência prática com **arquitetura de software, autenticação e autorização, PostgreSQL, JPA/Hibernate, Docker, testes automatizados, CI/CD, mensageria com RabbitMQ e integração entre aplicações Web, Backend e Mobile**.

Meu foco é transformar problemas de negócio em soluções de software organizadas, testáveis e escaláveis.

* 🎯 **Atuação:** Full Stack Developer | Java Backend Developer
* ☕ **Backend:** Java, Spring Boot, Spring Security, JPA/Hibernate, RESTful APIs
* ⚛️ **Frontend:** React, TypeScript, Next.js, Vite, Tailwind CSS
* 📱 **Mobile:** React Native, Expo, Expo Router
* 🗄️ **Dados:** PostgreSQL, MySQL, MongoDB, Supabase
* 🐳 **Infra & DevOps:** Docker, Docker Compose, GitHub Actions
* 🧪 **Qualidade:** JUnit, Mockito, MockMvc, Testcontainers, Vitest
* 📨 **Mensageria:** RabbitMQ / Spring AMQP
* 🧠 **Arquitetura:** Clean Architecture, Modular Monolith, Arquitetura em Camadas, SOLID
* 🌐 **Portfólio:** [wdenbergramos.vercel.app](https://wdenbergramos.vercel.app/)
